# Плеер (Vue Player)

Музыкальный плеер для локальных файлов с визуализатором звука и виниловой пластинкой, которая крутится во время воспроизведения.

**Демо:** https://danilromas.github.io/vue-player/

![Превью](docs/preview.png)

## Возможности

- добавление треков кнопкой или перетаскиванием файлов на окно
- визуализатор на Web Audio API (`AnalyserNode` + canvas): спектр и осциллограмма
- демо-трек, который синтезируется прямо в браузере через `OfflineAudioContext` и кодируется в WAV — можно потестить без своих файлов
- плейлист: сортировка перетаскиванием, удаление, длительность треков
- перемешивание, повтор плейлиста / одного трека
- перемотка по прогресс-бару (pointer events, работает и на телефоне)
- горячие клавиши и Media Session API — управление из шторки телефона и мультимедийными клавишами
- цвет интерфейса подстраивается под трек

Файлы никуда не загружаются — всё работает локально через `URL.createObjectURL`.

## Стек

Vue 3 (Composition API), Vite, Web Audio API, Canvas 2D.

## Запуск

```bash
npm install
npm run dev
```

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| Пробел | пауза / воспроизведение |
| ← / → | перемотка на 5 секунд |
| Shift + ← / → | предыдущий / следующий трек |
| ↑ / ↓ | громкость |
| M | выключить звук |
